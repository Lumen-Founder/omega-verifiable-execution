# 위협 모델(OmegaGraphEscrow + OVM0Dispute + omega_world)

- **자산**
  - 계정 예치금(대금)
  - 실행자 지분(bond·cover)
  - 분쟁 보증금(ETH)
  - 결과의 정확성(지급의 근거)
  - 출처 그래프의 무결성
- **신뢰 경계**
  - 체인(합의·검열 저항)
  - 판정자 계약(계정 소유자가 등급과 함께 허용)
  - 정직한 감시자 1명 이상
  - 토큰 계약(표준 ERC-20)
- **증거 등급:** 수학(정리·전수) / 모의(시험용 판정자) / 로컬(anvil 실제 거래) / 실제 통합(실네트워크, 미실행) / 독립 감사(미실행)
